# Setup Reel series

Six 10–14 second Reels built from watermarked product previews. Each has four
frames in `assets/social/reel-boards/<slug>/`.

## Publishing rules

- Publish Japanese and English as separate, native-language Reels. Do not mix them in one video.
- Use `01-hook.jpg` as the cover. Hold its first line for at least 1.2 seconds.
- Add a gentle 100–104% scale over 2.5–3 seconds to each still, with 0.15-second cuts.
- The watermarked preview must remain intact; never attach an original wallpaper file to social media.
- The caption should earn a save or a comment first. The profile link is the product path.

## Caption logic, based on the observed posts

The reference iPhone post by @heyeaslo uses a plain, personal promise — “Here’s
how I currently organize my iPhone” — and leaves the visual to do the aesthetic
work. The MacBook tip post makes the value equally explicit with “3 ... Tips,”
while the strongest setup captions add one practical question or save prompt at
the end. These captions preserve that pattern without copying their language:

1. Lead with a specific, reproducible outcome, not `minimal.` or a product name.
2. Explain the exact three choices shown in the Reel.
3. Ask one answerable question *or* ask for a save — never both as competing CTAs.
4. Mention the product/path only after the value. Use no inflated promises such as
   “change your life” or “the cleanest setup ever.”
