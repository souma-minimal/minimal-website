# Setup Reel series

Six 10–14 second Reels built from watermarked product previews. Each has four
frames in `assets/social/reel-boards/<slug>/`.

## Publishing rules

- Publish Japanese and English as separate, native-language Reels. Do not mix them in one video.
- Use `01-hook.jpg` as the cover. Hold its first line for at least 1.2 seconds.
- Add a gentle 100–104% scale over 2.5–3 seconds to each still, with 0.15-second cuts.
- The watermarked preview must remain intact; never attach an original wallpaper file to social media.
- The caption should earn a save or a comment first. The profile link is the product path.
